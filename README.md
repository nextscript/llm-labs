## About

Every file in this repository is either a test prompt or the result of running it through an LLM. This repo is a record of test runs — each prompt is paired with the output it generated.

Results may include code (HTML, PHP, and more) generated by the model. There is no standalone application or build process — any code here is the output of a test, not a maintained project.
